# Практика. Урок 7: потокобезопасный LRU-кэш

Пакет `lrucache`: LRU-кэш, защищённый `sync.RWMutex`. Каркас типа `Cache`
(поля `cap`, `mu`, `data`, `lru`) задан — реализуйте логику LRU и
потокобезопасность.

## Задание

Реализуйте `TODO` в `lrucache/cache.go` (лекция: разделы «Mutex/RWMutex»,
«Подводные камни»):

1. `Get` — под `Lock` (он меняет порядок `lru` — `RLock` недостаточно):
   промах `("", false)`, попадание — значение + перенос ключа в конец `lru`.
2. `Put` — под `Lock`: `cap < 1` — no-op; существующий ключ — обновить
   значение и recency; новый — добавить и при переполнении вытеснить
   `lru[0]` (удалить его из `data` и из `lru`).
3. `Delete` — под `Lock`: удалить из `data` и из `lru`; несуществующий ключ —
   не ошибка.
4. `Len` — под `RLock` (чистое чтение): `len(data)`.

Инварианты (их проверяют тесты):

- `Len` никогда не превышает `cap`;
- каждое попадание в `Get` обновляет recency ключа;
- при конкурентном доступе значения не искажаются.

Запускайте тесты с race detector — это главный критерий практики:

```sh
go test -race ./...
```

## Критерий сдачи

```sh
go mod tidy

go test -race ./...
```

Всё зелёное.
