# Go для промышленной разработки

Курс для разработчиков с опытом 10+ лет на Python, C# или JavaScript. Мы не проходим
«синтаксис с нуля» — мы переносим уже имеющиеся инженерные навыки на Go и решаем
реальные промышленные задачи: конкурентность, сеть, микросервисы, производительность,
эксплуатация. На каждом шаге — осознанное сравнение с привычными языками, в первую
очередь с Python.

## Как устроен курс

- **12 недель, 24 урока** — по 2 урока в неделю, примерно 6–8 часов в неделю.
- Каждая неделя — каталог `week-NN/`, каждый урок — каталог `lesson-YY/`:
  - `lecture.md` — лекция на русском (код и термины на английском);
  - `practice/` — шаблон домашнего задания: каркас кода с `TODO` вместо ключевых
    фрагментов и **готовые тесты**.
- **Сквозной проект** — микросервис заказов. Каждое ДЗ наращивает его: от доменной
  модели через HTTP/gRPC, PostgreSQL и Kafka до Kubernetes. Контракт проекта:
  [CAPSTONE.md](CAPSTONE.md).
- **Критерий сдачи** — `go test ./...` зелёный (+ `go vet`, а с первого урока — и
  линтер). Эталонных решений нет: как в реальной работе, критерий приёмки — тесты и
  ревью инструментов.

## Как работать с практикой

```sh
cd week-01/lesson-02/practice
go mod tidy        # подтянуть зависимости
go test ./...      # тесты красные — это норма, они и есть задание
# ...реализуйте TODO из каркаса, всё необходимое есть в lecture.md...
go vet ./...
go test ./...      # зелёные — домашняя работа сдана
```

После этого выполните раздел «Перенос в капстоун» из `practice/README.md` — так
сквозной проект растёт от урока к уроку.

## Принципы курса

1. **Синтаксис — по необходимости.** Никаких «что такое переменная»: синтаксис
   подаётся короткими вставками внутри практических тем.
2. **Go vs Python в каждой лекции** — конкретно: `asyncio` vs goroutine-планировщик,
   GIL vs параллелизм, `FastAPI/uvicorn` vs `net/http`, исключения vs многозначный
   возврат, `pydantic` vs структуры. Где уместно — аналогии с C#/JS.
3. **Тесты — критерий приёмки.** Домашняя работа считается сделанной, когда
   `go test ./...` зелёный и `go vet` молчит.
4. **Один сквозной проект.** Никаких разрозненных сниппетов: к концу курса — рабочая
   микросервисная система, а не коллекция упражнений.
